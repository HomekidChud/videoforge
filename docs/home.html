Video editing your AI can actually drive.

VideoForge is a browser-based video editor with a strict HTTP API, real-time collaboration, live streaming, and motion-graphics primitives that both humans and LLM agents can work with.

Read the docs API reference
◆

Motion graphics

Rectangles, ellipses, lines and progress bars with keyframable width, height and progress — composable into lower thirds, title cards and badges.

⚡

Strict HTTP API

Every timeline edit is a validated, revertible operation. No silent best-guess behaviour — invalid input throws.

👥

Live collaboration

Real-time cursors, presence, and shared timelines over WebSocket. See teammates move as you edit.

🎬

Server-side render

Export MP4 via FFmpeg with the same geometry the browser preview uses — preview and export agree by construction.

Add a lower-third in one API call

POST /api/v1/projects/:projectId/timeline
{
  "ops": [
    { "op": "apply_graphic_preset",
      "args": { "preset": "lower-third",
                "id": "lt1", "start": 0, "duration": 4 } },
    { "op": "add_text_clip",
      "args": { "text": "Hello, world",
                "start": 0.2, "duration": 3.6,
                "x": 0.30, "y": 0.84 } }
  ]
}
