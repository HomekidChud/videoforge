## What you will see

{{video:tour}}

The Studio is arranged in four areas: the tool dock and library on the left, the preview in the middle, the inspector on the right and the timeline along the bottom. The video above is a three minute tour of each one. Use its chapter list to jump to a part.

> [!TIP] The Studio offers a short tour of its own the first time you open it. Replay it at any time from the More menu, under Help.

## The tool dock

The narrow column of icons on the left is the tool dock. Each icon opens one panel in the library beside it.

| Icon | Panel | What it holds |
|---|---|---|
| Media | Media | Footage, music and images for this project |
| Effects | Effects | Motion presets and transitions to drag onto clips |
| Graphics | Graphics | Titles, shapes and ready made templates |
| Blocks | Blocks | The block studio, for building repeatable edits |
| Tools | Tools | Saved scripts you can run against the timeline |
| Projects | Projects | Every project you have saved |

Hover over an icon to see its name. Blocks and Tools are part of Advanced mode.

## Workspaces

The workspace switcher at the top of the Studio rearranges the panels for one kind of work. Your last choice is remembered in this browser.

| Workspace | Arrangement |
|---|---|
| Edit | Library, preview, inspector and timeline: the default |
| Animate | The library is hidden and the timeline grows, so keyframes have room |
| Graphics | The Graphics panel opens beside the preview |
| Audio | A taller timeline with the graphics track collapsed |
| Blocks | Opens the block studio (Advanced mode) |

## The timeline

Titles and shapes sit on the Graphics track, footage on the Video track and music or voice over on the Audio track. Select a clip and press S to split it at the playhead, or drag its edges to trim it. Use the arrow beside a track name to collapse the track, and the overview strip above the ruler to move around a long edit.

## The inspector

The inspector shows the settings for the current selection. With nothing selected it shows the project settings. The search box at the top narrows the list to the sections that mention your words, so typing opacity jumps straight to it.

Advanced mode shows every section. Simple mode hides the rarely used ones, such as Fit to frame, Fades and Transition in. Switch modes from the More menu at the top right of the Studio.

## The command palette

Press Ctrl+K to open the command palette. It lists every action in the Studio, groups them by task and shows the keyboard shortcut beside each one. The commands you used most recently appear first.

## Keyboard shortcuts

Press the question mark key to open the shortcut sheet. The full list is also on the [Keyboard shortcuts](keyboard-shortcuts) page.
