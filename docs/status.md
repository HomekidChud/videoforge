## What you are looking at

The hosted API server is <https://videoforge-api-s54w.onrender.com>. It is the deployment the introduction, quickstart and self-hosting pages point to, and it sleeps when idle: free hosting pauses inactive servers, so the first request after a pause can take a few seconds to wake it.

If it stays down, the deployment is broken rather than asleep — check the repository's GitHub Pages deployment, or run your own server from the self-hosting guide.

> [!TIP] Self-hosting is the supported way to use VideoForge: your uploads stay on your disk, renders use your FFmpeg, and nothing sleeps.
