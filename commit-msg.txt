Fix sign-out loop for split deployments (GitHub Pages app + Render API)

The app is served from homekidchud.github.io and the API from
videoforge-api-s54w.onrender.com, so every API call is cross-site — and
browsers refuse to send SameSite=Lax cookies on cross-site requests.
Login set the session cookie, the very next /api/auth/me sent nothing,
and the app bounced back to the sign-in page.

- Session (and OAuth state) cookies now relax to SameSite=None; Secure
  when the request comes from a different site over HTTPS; same-origin
  and same-site requests keep Lax. Regression-tested: Lax same-origin,
  None + Secure for a github.io origin against the API host.
- Google sign-in now returns to the SPA origin (CORS_ORIGIN) instead of
  the API's own host after the callback.
